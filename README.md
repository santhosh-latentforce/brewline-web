# Brewline web

The marketing site for Brewline, our specialty coffee subscription.

Vite, React 19, TypeScript and Tailwind CSS 4. Brand colours and fonts are theme tokens in `src/index.css`
(`espresso`, `roast`, `caramel`, `crema`, `cream`; `font-display` is Fraunces, the body is Inter).

```sh
npm install
npm run dev
```
